# phpshop

This repository contains legacy PHP shop application code and was automatically exported from the Google Code project `phpshop`.

## Repository layout

- `phpshop1/` contains one application tree, including an `index.php` entry point.
- `phpshop2/` contains a second project tree.
- The first tree includes administration module code under `WEB-INF/modules/admin/`.

## Working with the project

Inspect the selected application tree and its configuration before preparing a PHP/web-server environment. The root does not provide a verified installation procedure or a supported PHP version. Check database and extension requirements in the code, configure private settings outside committed documentation, and evaluate compatibility before exposing this legacy application to a network.
